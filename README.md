# 🌿 ScenicRoute (De Mooiste Route App)

Een gebruiksvriendelijke webapplicatie gebouwd met **Python** en **Streamlit** die in plaats van de kortste route, de **mooiste route** berekent op basis van jouw gewenste afstand of tijd.

## ✨ Kenmerken
1. **Navigatie op maat**: Geen saaie snelste wegen, maar routes langs natuur, water en rustige paden.
2. **Afstand of Tijd**: Geef op hoeveel kilometer je wilt afleggen of hoeveel tijd je hebt. De app berekent automatisch de bijbehorende route.
3. **Lus-ondersteuning**: Kies eenvoudig of je wilt eindigen waar je gestart bent (ronde / lus) of van A naar B wilt reizen.
4. **Uiterst gebruiksvriendelijk**: Schone en intuïtieve interface die direct werkt op zowel desktop als mobiel.

## 🚀 Aan de slag (Lokaal draaien)

1. Clone deze repository naar je computer:
   ```bash
   git clone https://github.com/jouw-gebruikersnaam/scenic-route-app.git
   cd scenic-route-app
   ```

2. Installeer de benodigde packages:
   ```bash
   pip install -r requirements.txt
   ```

3. Start de Streamlit app:
   ```bash
   streamlit run app.py
   ```

## 🌐 Publiceren op Streamlit Cloud (Gratis & Direct Online)
1. Maak een nieuwe public repository aan op GitHub en upload `app.py` en `requirements.txt`.
2. Ga naar [share.streamlit.io](https://share.streamlit.io/).
3. Log in met GitHub en klik op **New app**.
4. Selecteer je repository, branch (`main`), en geef als hoofdbestand `app.py` op.
5. Klik op **Deploy!** Je app is nu wereldwijd bereikbaar via een eigen URL.
